# Disciple.Tools - Bulk Contact Messaging (Deprecated)

> **This plugin is deprecated and no longer maintained.** Bulk messaging is built into the Disciple.Tools theme as of version 1.58.0. Deactivate and delete this plugin.

In the theme, open a list page (for example Contacts), choose **Actions → Bulk Send Message**, select the records and send an email to each one. The message supports placeholders such as `{{name}}`. To send magic links in bulk, use **Actions → Bulk Send App**.

The final release of this plugin loads nothing, so it does not conflict with the theme while it is still installed.
